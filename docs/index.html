Formula Substitution Engine A + B → C

When two ingredients in a formula can be replaced by one pre-blended accord, the engine finds the pair and swaps it. Every rule sits in a HashMap keyed by the ingredient pair, so each check costs O(1) no matter how big the rule book is. A manual top-to-bottom check costs O(R).

04How it works in Java

The core is plain Java with no framework code, so it is easy to unit-test. Spring Boot wraps it with a REST API and the SQL database.
